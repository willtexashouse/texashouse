# Prompt blocks

The fixed blocks from `brand/VISUAL_LANGUAGE.md` §3, kept as plain text so
they are copied verbatim into every prompt and never retyped.

Assemble in this order: `block-1-style` + `block-2-texture` + one
`block-3-*` (by tier) + a fresh Block 4 story under 120 words +
`block-5-negative`, then the tool parameters (`--ar`, `--style raw`,
`--sref`). For Higgsfield, attach the approved Midjourney reference and use
only blocks 1, 4, and 5.

`hero-globe.txt` is the one description used everywhere the globe appears.
