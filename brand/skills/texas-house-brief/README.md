# texas-house-brief

A Claude skill for building branded Texas House working documents.

- `SKILL.md` — the rules Claude follows.
- `assets/template.html` — the document shell: licensed fonts embedded, full
  token set, every component, the feedback drawer, the revisions panel, mobile
  behaviour. Copy this; never rebuild it.

## Use it in Claude Code
Already installed at `~/.claude/skills/texas-house-brief/`. Any session on this
machine can use it. Ask for a Texas House brief, memo or review document.

## Use it in a Claude chat on claude.ai
Upload `texas-house-brief.zip` under Settings, Capabilities, Skills. Then ask a
chat for a Texas House document and it will follow the same rules and start from
the same template.

Fonts in the template are licensed to Texas House. Keep the skill inside the
organisation.
