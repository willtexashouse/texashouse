# Same Land — Midjourney shot list

Every still the homepage evolution video needs, as ready-to-paste Midjourney
prompts. Will generates these in Midjourney, picks one per scene, upscales
it, and drops the files into `brand/inbox/` named as listed. Claude Code then
attaches each approved still as the reference for its Seedance clip and for
every downstream Higgsfield pass.

Companion to `homepage-evolution-video.md`. Blocks 1, 2, 3 and 5 are copied
verbatim from `brand/prompts/`; Block 4 is written per scene.

## How to run them

- Paste each prompt whole. Add your editorial `--sref` at the end of every
  one, the same code every time. Once chapter 1 is approved, keep using that
  same sref for the other five so the six frames read as one publication.
- Parameters on every prompt: `--ar 21:9 --style raw --s 150`.
- Generate four to eight, pick one. Look for: subject small in frame,
  horizon just below the middle, sky owning the upper half, all movement
  reading left to right, sun at the right horizon.
- Upscale the pick, save as PNG, drop it in `brand/inbox/` with the filename
  given under each scene.

Rules held in every prompt:

- **Left to right.** Every horse, plume, crane, rocket and camera drift moves
  to the right. Nothing moves against the read.
- **One horizon.** The horizon line sits at the same height in every chapter,
  just below the middle of the frame, until chapter 6 where it becomes the
  curve of the Earth.
- **One light.** Late afternoon, sun low at the right horizon, in chapters 1
  through 5. Chapter 6 replaces the sun with Earth glow.
- **One warm against one cool** in every frame.

## After the files land

1. Claude Code runs `npm run hf -- intake` on each file so it is named,
   filed in `public/brand/` and logged in `brand/renders.md`.
2. The style paragraph is written from the approved A1 and reused verbatim.
3. Each chapter clip is generated in Seedance 2.5 with its A frame as the
   start image and the following B plate as the end image, 5 to 8 seconds,
   slow drift to the right, minimal subject motion.
4. Chapter 6 has no B plate after it. It holds.
