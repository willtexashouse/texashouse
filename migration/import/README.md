# Webflow → Sanity import

Transforms the Webflow exports in `../webflow-export/` into Sanity documents and
imports them into the `production` dataset of project **naolvj96**.

`transform.mjs` reads the local CSV/JSON exports and writes a single NDJSON file
(`dist/texashouse.ndjson`). Images are referenced by their Webflow CDN URL via
the `_sanityAsset` shorthand, so the importer downloads + uploads them for you.

## What gets imported (136 docs)

| --- | --- | --- |
| topic | 24 | `json/tags.json` (deduped: innovation/cuisine) |

~230 images are pulled from the Webflow CDN during import.

## Run it (locally — the cloud sandbox can't reach Sanity)

> Must run on your own machine. The hosted dev sandbox blocks outbound traffic
> to Sanity's API, so the import has to run somewhere with normal internet.

1. Clone the repo and install deps (once):
   ```bash
   git clone <repo> && cd texashouse
   npm install
   ```
2. Create a Sanity **Editor** token: sanity.io/manage → project **Texas House**
   → **API → Tokens → Add API token** (Editor). Copy it.
3. Run the import with the token:
   ```bash
   SANITY_AUTH_TOKEN=<your-editor-token> npm run import
   ```
   That builds the NDJSON and imports it. `--replace` makes it safe to re-run
   (re-importing updates existing docs by `_id`).

Prefer not to use a token? Run `npx sanity login` first, then `npm run import`.

## Notes

- Re-running is idempotent (stable `_id`s + `--replace`).
- Drafts in Webflow are skipped.
- `dist/` is git-ignored — it's regenerated by `npm run import:build`.
- The featured article is "Texas House Goes Global: A Landmark Day at SXSW
  London"; article topics are a curated best-guess (only 4 articles) — easy to
  adjust later in the Studio.
