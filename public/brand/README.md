# Brand renders

Approved imagery from the pipeline in `brand/VISUAL_LANGUAGE.md`.

Naming: `tier-register-subject-aspect-v#.ext`, for example
`scene-orbit-robot-coffee-21x9-v2.png`. Sequences: `seq-eras-0001.webp`
through `seq-eras-0240.webp`. Keep the source prompt for each file in
`brand/renders.md` next to its filename so any image can be regenerated.
