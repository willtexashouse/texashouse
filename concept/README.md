# Concept Work

Early concept work for the Texas House website rebuild — drafts, wireframes,
prototypes, and mockups that explore directions before we commit to a build.

This is a sandbox: things here are meant to be iterated on and thrown away.
Once a direction is chosen, it graduates into the production `src/`.

## Design import

The branded design is built in **Claude Design** and exported as React +
Tailwind. Land the export in `concept/design-import/` first for review, then
port components into `src/components/` and wire them to Sanity (see
`docs/build-plan.md`).
